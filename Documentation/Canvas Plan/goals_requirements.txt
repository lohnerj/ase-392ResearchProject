Summary of the Project
Use machine learning in order to predict if the price of various items will raise or drop in the future.

Goals
Develop the architecture/design for the database and front-end interface. 
Enhance/change database structure and optimize for more data/machine learning applications.
Implement the front-end interface for the machine learning module. 
Expand the API suite to support the upgraded database functionalities. 
Integrate new APIs into the front-end system.
Evaluate various machine learning algorithms for optimal performance. 
Integrate the selected machine learning algorithm into the production codebase. 
Assemble all components into a cohesive system. 
Refactor code for efficiency and maintainability. 
Complete and refine the project documentation. 
Conduct backend testing. 
Conduct front-end testing.
To create an easily accessible user interface that allows for users to easily see and use market information.

Why?
Create a useful tool for people to manage the complexity of the in-game market, while also providing useful analytics.

Features
User Story Requirements:

1.0: As a developer, I want to develop the architecture for the database and front-end interface so that we have a robust foundation for the application.

 

1.1: As a data engineer, I want to enhance the database structure and optimize it to handle more data and support machine learning applications, ensuring efficient data processing and retrieval.

 

1.2: As a front-end developer, I want to implement the interface for the machine learning module to provide users with an interactive and user-friendly experience.

 

1.3: As a backend developer, I want to expand the API suite to support the enhanced database functionalities, allowing seamless interaction and integration across different system components.

 

1.4: As a front-end developer, I want to integrate the new APIs into the front-end system to ensure all components communicate effectively and data flows seamlessly.

 

1.5: As a software engineer, I want to evaluate various machine learning algorithms to determine which one performs optimally for our specific needs.

 

1.6: As a software engineer, I want to integrate the selected machine learning algorithm into the production codebase to enable practical application and real-world testing.

 

1.7: As a software engineer, I want to assemble all components into a cohesive system to ensure functionality and smooth operation across all parts of the application.

 

1.8: As a developer, I want to refactor code for efficiency and maintainability to ensure the application is easy to manage and update.

 

1.9: As a software engineer, I want to complete and refine the project documentation to provide clear and comprehensive guidance for users and future developers.

 

1.10: As a software engineer, I want to conduct comprehensive backend testing to ensure that all server-side functions operate correctly and meet performance standards.

 

1.11: As a software engineer, I want to conduct rigorous front-end testing to ensure the user interface is reliable, efficient, and user-friendly.
